# [WIP] ShapoNES

an NES emulator for my programming study.

> [!CAUTION]
> It is still in the trial-and-error phase and will be subject to frequent changes.
>

This fork add two versions for PicoCalc or PicoCalc emulator (https://scalarcalc.itch.io/picocalc-emulator)
 - shapones_picocalc_pico1.uf2 - For RP2040 processor
 - shapones_picocalc_pico1.uf2 - For RP2350 processor

Note: PicoCalc emulator has been optimized to use this NES emulator
